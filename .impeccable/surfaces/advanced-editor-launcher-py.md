# 고급 편집기 화면 브리프

- 범위/모드: `advanced_editor/launcher.py`의 Windows PyQt6 편집 화면, Operate.
- 사용자 작업: 번역 영역을 선택하고 텍스트·글꼴·OCR·마스크·인페인팅을 반복 조정하며 결과를 즉시 확인한다.
- 성공 조건: 실행 취소·다시 실행 후 별도 클릭 없이 최신 상태가 보이고, 편집 도구와 설정을 왼쪽 한 방향에서 찾을 수 있다.
- 보존 조건: 기존 기능, 단축키, 세션 형식, 출력 호환성을 유지하고 번역 파이프라인과 공용 코어는 건드리지 않는다.
- 선택한 방향: Tubik/Ribbet식 얇은 왼쪽 도구 레일 + 왼쪽 설정 패널 + 넓은 중앙 캔버스 + 오른쪽 다중 이미지 목록 + 최소 상단 작업 표시줄.
- 기억할 장면: 도구를 왼쪽에서 고르고 바로 옆 설정을 바꾸면 중앙 만화 페이지가 즉시 갱신된다.
- 고정 패널 순서: `[왼쪽 도구 메뉴] [편집 상세] [만화 캔버스] [사진 목록]`. 사진 목록은 여러 장 작업에서만 오른쪽 끝에 표시한다.
- 텍스트 입력 밀도: 원문과 편집 텍스트 상자는 작게 시작하고, 오른쪽 아래 대각선 손잡이로 높이를 직접 늘리거나 줄인다.
- 상단 작업 표시줄: 왼쪽에 아이콘이 있는 실행 취소·다시 실행·접이식 이름별 기록과 브러시 크기를 두고, 저장·내보내기는 오른쪽 끝에 둔다. 브러시 크기 숫자는 상세 패널과 같은 `밝은 값 면 + 중앙 정렬 ▲▼ 스테퍼`로 표시한다.
- 도구 명명: 모든 버튼은 의미가 맞는 선형 아이콘과 이해 가능한 전체 한국어 이름을 함께 쓴다. 특히 인페인팅/그리기/원본 복구의 브러시와 지우개를 `지우기`처럼 축약하지 않는다.
- 시각 마감: 50px 잉크 상단바, 16px 편집 패널 인셋, 10px 세로 리듬, 1px 패널 경계와 섹션 구분선을 사용한다. 흰 필드·옅은 청회색 패널·차콜 캔버스의 재질 위계를 유지하고 카드와 그림자를 남발하지 않는다.
- 저장 피드백: 저장 성공 시 창 오른쪽 아래에 저장 아이콘과 `<파일명> 저장 완료` 토스트를 표시하고 2.4초 뒤 자동으로 숨긴다. 저장 실패는 기존 오류 대화상자를 유지한다.
- 캔버스 영역 표식: 번호는 8px 글자의 직각 어두운 탭으로 표시하고 박스 좌상단 테두리에 1px 겹쳐 한 몸처럼 붙인다. 충돌 여부와 관계없이 위치를 바꾸지 않는다. 일반 테두리는 1px, 선택 테두리는 2px로 유지한다. 선택 시 7px 리사이즈 핸들은 각 꼭짓점 바깥 대각선 방향으로 2px 띄워 박스 모서리와 번호 탭을 가리지 않으며, 실제 클릭 영역은 더 넓게 유지한다.
- 상황별 상세 패널: 왼쪽 상세는 `텍스트·배치 / 도구 설정` 두 탭으로 나눈다. 텍스트 수정과 위치·크기·글꼴 조정은 한 화면에 두고, 좌표·크기 값은 3×3 그리드로 압축해 1200×760 창에서도 스크롤 없이 보이게 한다. 선택 도구명은 왼쪽 레일에서 이미 보이므로 상세 상단에서 반복하지 않으며, 도구를 바꾸면 가장 관련 있는 탭과 하위 탭만 자동으로 연다.
- 텍스트 정렬: 드롭다운 대신 왼쪽·가운데·오른쪽 정렬 아이콘 3개를 항상 노출하고, 현재 값 하나만 선택 상태로 표시한다. 기존 세션의 `left/center/right` 저장값은 그대로 유지한다.
- 드롭다운: 모든 콤보박스는 오른쪽 28px 회청색 확장면, 얇은 왼쪽 구분선, 중앙 정렬된 선형 꺾쇠를 직접 그린다. hover/open 상태는 옅은 파랑으로 표시하고 열린 동안 꺾쇠 방향을 반전한다. QSS의 네이티브 화살표 교체에 의존하지 않으며 Windows 기본 확장 버튼은 그리지 않는다.
- 왼쪽 도구: 기본·인페인팅·그리기·원본 복구를 얇은 구분선과 작은 섹션명으로 나누고, 반복되던 범용 브러시/지우개 대신 작업 성격이 드러나는 고유 선형 아이콘을 사용한다. 원본 복구 브러시와 지우개는 작은 반짝임 입자를 공유해 한 쌍의 복원 도구로 읽히게 한다.
- 텍스트·배치 폴리싱: 글꼴 가족·굵기를 정렬/렌더링/세로쓰기 바로 아래에 둔다. 렌더링·세로쓰기는 아이콘과 명확한 선택 면을 가진 컴팩트 토글로 표시한다. 숫자 필드는 균일한 3×3 그리드로 두고 각 칸을 `은은한 의미 아이콘 → 고정 폭 제목 → 밝은 값 입력면 → 오른쪽 위·아래 조절 버튼` 순서로 읽히게 한다. 제목 면은 한 단계 어둡게 분리하고 제목 뒤 세로선은 모두 맞춘다. 조절 버튼은 아이콘을 정중앙에 두며 사이를 가는 수평선으로 나눈다. 굵게·기울임·굵게+기울임은 실제 마크업 상태를 눌린 버튼으로 보여주고, 글자/외곽선 색은 색 면과 HEX 값을 함께 표시한다.
- 실행 취소/다시 실행: 18px에서도 방향과 되돌아가는 동작이 분명하도록 굵은 원호와 채운 삼각형 머리를 쓴 서로 대칭인 원형 되돌림 화살표를 사용한다. 단축키는 실행 취소 `Ctrl+Z`, 다시 실행 `Ctrl+Shift+Z`로 고정한다.
- 이미지 목록: 여러 장 작업에서만 오른쪽 끝에 표시하며 상단 작업 표시줄에서 접을 수 있다. 현재 편집 페이지와 선택 장수를 함께 표시하고 전체 선택·선택 해제를 제공한다.
- 다음 결정: 실제 편집 세션에서 패널 자동 전환이 반복 작업을 방해하지 않는지와 좁은 화면의 상단바 밀도를 검증한다.


## 선택 영역 재번역 확장 (2026-10-12)

- Scope: 기존 Windows PyQt6 고급 편집기 Operate 화면에 한 번의 번역 제안만 추가한다. 원문·편집 텍스트·글꼴 컨트롤 위치, 두 탭, 도구 레일을 보존한다.
- FORM: 기존 얇은 청회색 상세 패널의 상단 우측 두 버튼 슬롯을 그대로 쓴다. 새 줄·탭·별도 도구 메뉴를 만들지 않는다. 두 실행 슬롯은 74×26px `AI 식자`와 80×26px `재번역 ▾`로 유지한다. 결과 열기는 캔버스 상단으로 분리한다. 기존 시각 세계를 상속하는 확장으로 새 방향 추첨은 적용하지 않는다.
- FIRST VIEWPORT: 원문과 편집 텍스트가 이전 좌표에 있고 그 위 우측에 AI 식자와 재번역이 보인다. 340/403/450px 패널에서 새 버튼 때문에 필드가 밀리지 않는다.
- VISITOR PATH: 영역 선택 → 재번역 또는 메뉴의 경상도 사투리/직접 요청 → 현재/새 문장을 비교 → 원하는 문장을 적용한다. 적용 전에는 기존 번역이 유지된다.
- SIGNATURE INTERACTION: 기본 버튼은 즉시 자연스러운 재번역을 요청하고 작은 메뉴는 말투를 고른다. 작업 현황과 경과 시간·중단은 기존 캔버스 확대 툴바의 오른쪽에서 보여준다. 준비된 번역안은 다시 열 수 있고 직접 다듬을 수 있다. 페이지·영역·원문·기존 번역이 바뀌면 이전 제안 적용을 거부한다.
- CROSS-SURFACE: 원문 없는 영역은 비활성, AI 이미지 영역은 캔버스 결과 버튼과 기존 표시 토글을 사용한다. 서버 오류·중단은 기존 문장을 유지하고 적용은 기존 저장·실행 취소 경로를 사용한다. 한 번의 요청은 전역 작품 규칙을 수정하지 않는다.
- Evidence boundary: native Qt offscreen 캡처와 모의 응답으로 검증한다. 실제 외부 번역 품질과 서버에서 이미 실행된 요청의 취소는 이 검증에 포함되지 않는다.

## AI 작업 현황·결과 위치 확장 (2026-10-13)

- 승인: 사용자가 네 상태(대기/식자 진행/재번역 진행/완료) 목업을 본 뒤 `진행해`로 구현을 승인했다. `중단` 옆의 사각 아이콘은 체크박스로 오해돼 텍스트만 쓰기로 했다.
- 승인 참고: `.impeccable/mocks/ai-job-feedback/reference.png`. 기존 세계를 잇는 native Qt 확장의 배치 참고이며 새 시각 세계를 만드는 comp reproduction은 아니다.
- THESIS / OWN-WORLD: 기존 청회색 인스펙터와 차콜 캔버스의 위계를 유지하며, 실행은 왼쪽 인스펙터 상단 우측, 진행·결과는 캔버스 확대 툴바 오른쪽으로 모은다.
- STORY / FIRST VIEWPORT: 원문·편집 텍스트 필드는 이전 좌표를 유지한다. 두 실행 버튼은 진행 중에도 같은 이름과 위치로 남는다. 현황은 작업 종류·페이지·영역 번호, 실제 단계, 경과 시간을 표시한다. 완료 추정 시간과 가짜 진행률을 표시하지 않는다.
- FORM: 기존 확대·이동 툴바 한 줄 안에 최대 370×30px 현황을 둔다. 공간이 부족하면 80×30px 요약 버튼으로 접고 클릭 시 360px 현황 팝업을 연다. 340/403/450px 인스펙터에서 기존 필드 좌표를 보존한다.
- INTERACTION: 진행 중 텍스트 `중단`, 완료 후 `비교·적용`, 적용된 AI 이미지에서는 `결과 보기`. 완료 시 비교창은 자동으로 열리지 않는다. 다른 페이지에서 결과를 열면 원래 작업 페이지·영역으로 돌아가며 변경된 원문·번역·배경은 적용을 거부한다. 현황 닫기는 준비된 결과를 지우지 않는다.
- Evidence: `.impeccable/review/ai-job-feedback/`의 Windows Qt 캡처; offscreen 모의 응답으로 중단·오류·페이지 이동·비교·적용·저장·실행 취소를 확인한다. 실제 외부 API 호출·번역/이미지 품질·서버 요청 취소 보장은 포함되지 않는다. HTML/CSS detector는 native PyQt6 화면에 적용하지 않는다.

## 길쭉한 AI 식자·실패 결과 확인 (2026-10-14)

- 좁고 긴 crop은 흰 여백을 둔 정사각형 참조로 전송하며, 완료 후 여백을 제거해 원래 영역을 복원한다. 글자를 비등방으로 늘리지 않는다.
- 실패 생성 이미지가 있으면 기존 캔버스 현황의 `결과 보기`를 활성화한다. 기존 비교창을 읽기 전용으로 사용하며 `결과 폴더 열기`와 닫기만 제공하고 적용은 숨긴다. 입력 필드·실행 버튼·탭 위치는 유지한다.
- 실패 이미지·참조·치수·사유 보고서는 요청 assets 폴더에 유지한다. 실제 외부 생성 품질은 모의 응답 검증과 구별한다.

- 박스 경계 보정: 첫 참조는 선택 bbox만 포함하고 전체 페이지는 로컬에만 유지한다. 좌표는 실제 1024px 참조 기준이며, 박스 바깥의 새 획을 발견하면 합성 전에 거부한다. 선택 박스 크기를 임의 확장하지 않는다.

## 선택 영역만 전송 (2026-10-21)

- AI 식자는 현재 편집 배경의 선택 bbox와, 필요한 경우 같은 bbox의 원본 글자만 참조로 전달한다. 전체 페이지 참조는 보내지 않는다.
- 브러시·인페인팅 반영과 편집 텍스트 제외, 박스 경계 검사, 명시적 비교·적용은 유지한다. 선택 영역 밖의 배경 문맥은 생성에 제공되지 않으며 선택 영역 자체에 대한 서비스 검사는 그대로 적용된다.

## 글씨 덮기 브러시 (2026-10-24)

- 왼쪽 기존 도구 레일의 원본 복구 아래에 `글씨 덮기` 그룹과 브러시·지우개를 둔다. 기존 아이콘 선 두께·190×38px 도구 버튼·204px 레일을 유지한다.
- 기존 상단 마스크 브러시 크기를 공유하며 1px부터 지원한다. 선택 시 기존 편집기 설정 탭으로 이동하며 새 탭은 만들지 않는다. 같은 탭에서 덮기 전체 지우기와 짧은 설명을 제공한다.
- 독립된 `text_cover_mask_path`는 모든 텍스트 렌더 뒤에 원본 픽셀을 합성한다. 일반 복구·인페인팅·AI 배경 순서는 유지한다. 실행 취소/다시 실행·세션 이동·저장·이동 가능한 PNG 패키지에서 마스크를 보존한다.
- Windows Qt 1480×920/1120×760 합성 fixture 캡처와 원본 픽셀 비교로 확인한다. fixture는 동작 설명용이며 사용자의 실제 세션을 수정하지 않는다.
